# Content schema (CSV → ScriptableObjects)

All game content is authored as CSV in `Assets/_Game/Content/Source/` and imported with
**Tools/Game/Content/Import CSV Content** (batch: `-executeMethod Game.EditorTools.Content.ContentImporter.ImportBatch`).
The importer matches assets **by id**, creates missing ones, updates changed ones, never deletes (ids that disappear
from the CSVs are reported as orphans). It previews first and aborts on any parse error without touching assets.
English text in the CSVs is written to `Content/Localization/strings_content.csv` under generated keys (`<id>_name`, `<id>_lore`, `<id>_desc`, `<id>_text`).

Conventions: ids are lowercase snake_case (`hero_knight`). Lists inside a cell use `;`. Lines starting with `#` are comments.
Numbers use `.` as decimal separator. Enums are case-insensitive.

| File | Columns |
|------|---------|
| `config.csv` | `key,value` — `uniqueHeroAbilities` (validator: every hero has a passive, no two heroes share an active or passive behaviour), `partySize`, `currencies` (`id:Name;…`), `primaryCurrency`, `startingHeroes`, `startingCurrencies` (`id:amount;…`), `consumeShardsOnUnlock`, `shardOverflowCurrency`, `slotLayout` (`Weapon;…;Ring;Ring`), `inventoryLimit` (0 = unlimited), `equipmentRollVariation`, `rollVariationPercent`, `sellEnabled`, `starsEnabled`, `defaultStarTurnLimit`, `defeatConsolation` (table id), `currencyDropMultiplier`, `shardDropMultiplier`, `pityEnabled`, `pityFightsWithoutShard`, `showDropOdds`, `combat.minDamage`, `combat.defenseK`, `combat.maxRounds`, `combat.critChanceCap`, `combat.aiTargeting` (LowestHp/Random/First), `combat.powerWeights` (`Stat=w;…`), `shopEnabled`, `shopSlots` (`Weapon;Helmet;…`), `shopTierPrices` (price per gear tier, `150;300;…` = tier 1, 2, …), `shopRarityPrices` (`Common=1;Uncommon=2;…`: rarities on sale and their price multipliers) |
| `rarities.csv` | `rarity,color,equipmentStatMultiplier,shardsToUnlock,starCostMultiplier,dropWeightModifier,itemSellValue,overflowCurrencyPerShard` (one row per rarity) |
| `stars.csv` | `star,shardsRequired,currencyCost,statMultiplier` — star 1 is the unlocked state (costs ignored); costs are to reach that star from the previous one; shard cost × rarity `starCostMultiplier` |
| `ranks.csv` | `rank,hpMultiplier,xp,minSkills` — one row per enemy rank, weakest first (`Minion`, `Soldier`, `Elite`, `Champion`, `Boss`). `hpMultiplier` scales the enemy's max HP in battle (after the fight's multiplier); `xp` = player XP per defeated enemy; `minSkills` = skills besides the basic attack (active, passive, extra skills, specials): an enemy has at least its rank's and fewer than the next rank's. All three must climb rank by rank |
| `levels.csv` | `level,xpToNext,reward` — player levels 1..N (generated by `gen_campaign.py`); `reward` = drop table rolled on reaching the level; the last row is the cap |
| `skilllevels.csv` | `level,goldCost,potency` — gold-bought levels for each hero's active and passive; level 1 = as authored (potency 1, cost ignored); `goldCost` reaches that level from the one below; `potency` multiplies damage, healing, shields, DoT/HoT, stat changes, thorns, marks, %HP damage and revive HP (durations, cooldowns and chances never change) |
| `skills.csv` | `id,name,description,targeting,targetCount,cooldown,initialCooldown,effects,threshold` — `threshold` only for boss specials: the HP ratio at which the special charges |
| `passives.csv` | `id,name,description,trigger,threshold,chance,cooldown,oncePerBattle,targeting,targetCount,effects` — passive skills (see below) |
| `heroes.csv` | `id,name,rarity,class,origin,maxHp,attack,defense,speed,critChance,critDamage,basicSkill,activeSkill,passive,tint,lore` — `origin` = story act (`act_1`..`act_8`), used by shard pools |
| `enemies.csv` | `id,name,rank,maxHp,attack,defense,speed,critChance,critDamage,basicSkill,activeSkill,passive,extraSkills,specials,tint,art` — `rank` from `ranks.csv` (older tables with `isBoss` still load); `extraSkills` = more actives (`;` list, Champions/Bosses) used after `activeSkill`, each with its own cooldown; `specials` = boss special attacks (`;` list, falling thresholds): each charges once when HP first drops to its `threshold` and fires on the boss's next turn, ignoring cooldowns and silence (a stun delays it); `art` = another enemy id whose generated art this one reuses, tinted. Validator: in every wave a higher rank has more HP than a lower rank |
| `equipment.csv` | `id,name,slot,rarity,tier,stats,setId` — `stats` = `Attack=12;MaxHp=5%` (`%` = percent modifier); `tier` = gear tier (one per act; `0` = unique item, only dropped by name) |
| `story.csv` | `id,speaker,speakerName,text` — `speaker` = hero/enemy id (uses its name) or any id + `speakerName` |
| `droptables.csv` | `table,group,minRolls,maxRolls,withoutReplacement,type,refId,rarity,slot,rarityWeights,weight,amountMin,amountMax` |
| `chapters.csv` | `id,order,name,clearReward,unlockConditions` |
| `fights.csv` | `id,chapter,order,name,waves,recommendedPower,dropTable,firstClearTable,starTurnLimit,preBeats,postBeats,unlockConditions,kind` — `kind` = `Main` (default) or `Side` (side quest: optional, opens only through `unlockConditions`, never counts toward chapter completion, stars or the unlock chain) |

## Mini-syntaxes
- **targeting**: `SingleEnemy, AllEnemies, SingleAlly, AllAllies, Self, LowestHpAlly, RandomEnemies, LowestHpEnemy` (lowest HP ratio), `HighestAttackEnemy, RandomAllies` (distinct), `AllOtherAllies` (relative to the caster's team; `targetCount` for RandomEnemies/RandomAllies). A taunting enemy overrides single-enemy picks.
- **effects** (joined by `|`, prefix `self>` to apply to the caster):
  `Damage:power` · `Heal:power` · `Shield:power:turns` · `Stun:turns[:chance]` · `Status:Stat:value:turns[:Refresh|Stack|Ignore[:maxStacks[:chance]]]`
  (power multiplies caster attack; status value is a percent: `0.25` = +25%, `-0.3` = −30%).
  Also: `Dot:burn|poison|bleed:power:turns[:stacking[:maxStacks[:chance]]]` (default Stack ×3; ticks at the start of the holder's turn, ignores shields) ·
  `Hot:power:turns` · `Drain:power:ratio` (heals the caster ratio × damage) · `Execute:power:threshold:multiplier` · `PctHp:ratio[:cap]` (ratio × target max HP, at most cap × attack, default 4) ·
  `Taunt:turns` · `Silence:turns[:chance]` (no active skill) · `Cleanse[:count]` (harmful effects + stun) · `Dispel[:count]` (buffs + shield; 0/none = all) ·
  `Revive:hpRatio` (one fallen ally of the caster's side, once per unit) · `Thorns:ratio:turns` · `Dodge:chance:turns` · `Cooldown:delta` (active cooldown) · `Mark:value:turns` (+damage taken).
- **passives** (`passives.csv`): `trigger` = `BattleStart` (heroes on the first wave, enemies when their wave spawns) | `TurnStart` | `AfterBasic` | `AfterActive` | `OnHitTaken` | `OnCrit` | `OnKill` | `OnAllyDeath` | `OnLowHp` (once, at or below `threshold`);
  `chance` (empty = always), `cooldown` (holder turns between triggers), `oncePerBattle`. Passives never trigger other passives.
- **waves**: spawns joined by `+`, waves separated by `/`, optional stat multiplier `enemy_id@1.2` — e.g. `enemy_goblin+enemy_goblin / enemy_goblin_king@1.5`.
- **drop groups**: `group` = `G` (guaranteed, always given) or any name; each named group rolls `minRolls..maxRolls` times and picks entries by `weight`; `withoutReplacement` prevents the same entry twice per clear. Group settings are read from the group's first row.
- **drop types**: `Currency` (refId = currency), `HeroShard` (refId = hero), `RandomHeroShardByRarity` (rarity; optional refId = origin pool `act_1+act_2`), `Equipment` (refId = template, rarity = item rarity), `RandomEquipment` (optional `slot`, optional refId = tiers `3` or `2+3`, `rarityWeights` = `Common=70;Uncommon=30`; tier-0 items are never random).
- **unlockConditions** (`;`-joined): `ClearFight:fight_id`, `MinPartyPower:500`, `HeroOwned:hero_id`. Empty = default (previous fight / chapter cleared).

## Adding content without the CSVs
Every type also has a `Create > Game > …` asset menu. A new hero = one `HeroDefinition` asset added to `GameConfig.heroes`
(and a drop that gives its shards). Run **Tools/Game/Validate Config** afterwards; builds are blocked on validation errors.

## Balance workflow (step 15)
- **Export**: `Tools/Game/Content/Export Tables to CSV` writes heroes/enemies/equipment/rarities/stars back from the assets (Inspector edits → spreadsheet). Export→import is a no-op (tested).
- **Fast simulations outside Unity** (seconds): `dotnet run -c Release --project DotnetTests/BalanceCli -- <command>`
  - `progression [seeds]` — greedy/casual/hardcore campaign runs (fights, losses, gold, walls, unlock times)
  - `fights casual 1` — win rate per fight at the casual player's first attempt
  - `tune` — re-fits enemy multipliers in fights.csv to target first-attempt win rates (weakest of 8 simulated players)
  - `recommend` — writes `recommendedPower` (median casual party power at first attempt)
  - `validate` — config validation on the CSVs
- **In the Editor** (`Tools/Game/Balance/…`): Fight Balance Simulator, Run Progression Simulator, Drop Simulator, Economy Report, Star & Stat Curves, Save Config Snapshot / Diff Last Two Snapshots. Reports go to `BalanceReports/` (git-ignored).

## Generated content ("The Hundred")
Most rows are written by scripts; each owns one `# ---- GENERATED by … ----` section (rows above the sections are hand-written):
- `python3 tools/content/gen_roster.py` — the 90 designed heroes in `tools/content/roster_design.py` (rarity rolled per hero, seed 100).
- `python3 tools/content/gen_campaign.py` — chapters 4–40, the extra fights of chapters 1–3, side quests, enemies, gear tiers, relics, drop tables and story beats from `tools/content/campaign_design*.py`. Re-running keeps tuned multipliers and recommended power for unchanged fights.
- Enemy ranks: `tools/content/bestiary_design.py` holds the 64 ranked enemies (8 per act), which chapters use them, and every boss's extra skill and special attacks; `gen_campaign.py` gives the older enemies the rank their skill count implies and builds rank-aware waves (Elites from a chapter's middle on, Champions in its last third and in side quests). It also writes `levels.csv`; `BalanceCli levels` shows the player level casual players have at each chapter (used to set `LEVEL_ACT_FROM`).
- Then `dotnet run -c Release --project DotnetTests/BalanceCli -- tune` (chapter by chapter; `tune from <n>` resumes) and `-- recommend`, and import the CSVs in Unity.
- Art: `tools/art/roster_generated.py` derives specs for new characters; `gen_characters.py`, `gen_items.py --generated`, `gen_ui.py`, `gen_backgrounds.py --chapters-only`.

## Gear shop and skill levels (owner request 2026-10-31)
- **Shop**: sells the `shopSlots` templates of the current gear tier = the highest tier named by `RandomEquipment` drops (`refId` tiers)
  in any unlocked main fight's drop/first-clear table or its chapter's clear reward (at least 1). Tier 0 items are never sold.
  The player picks a rarity from `shopRarityPrices`. Price = `shopTierPrices[tier]` × chosen rarity multiplier × the template's own
  rarity multiplier (a template whose own rarity has no multiplier is not sold). The validator rejects any price at or below the
  rarity's `itemSellValue` (no buy/sell gold loop).
- **Skill levels**: see `skilllevels.csv`. Stored per hero in the save (`activeSkillLevel`, `passiveSkillLevel`, v6).
