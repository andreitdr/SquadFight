# Privacy Policy — SquadFight

_Last updated: 2026-10-29_

SquadFight is a single-player game that works **completely offline**.

- **No personal data is collected.** The game has no accounts, no sign-in, no advertising, no analytics and no crash reporting service.
- **No network access.** The app does not request internet permission and never sends data anywhere.
- **What is stored on your device:** your game progress and settings, in the app's private storage. If your phone's system backup (Android Auto Backup / iCloud) is enabled, the operating system may include this file in your personal backup; the developer never receives it.
- **Bug reports are manual.** Settings → "Copy debug info" copies technical information (app version, device model, game progress summary, recent log lines) to your clipboard so *you* can paste it into an email if you choose. Nothing is sent automatically.
- **Children:** the game collects no data from anyone, including children.
- **Deleting your data:** uninstall the app, or use Settings → Reset progress.
